# Gym Interval Timer

An interval timer for a home gym with Spotify and Apple Music playlists: work and rest each get their own playlist, which keeps its place between intervals.

- Live site: https://stephenrcrandall-personal.github.io/gym-interval-timer/
- Sound check (run this first, on the iPad and a phone, with Spotify playing): https://stephenrcrandall-personal.github.io/gym-interval-timer/soundcheck/
